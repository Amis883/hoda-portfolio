# Hoda Kakhki – Portfolio

A modern, minimal portfolio built with Next.js, Tailwind CSS, and Framer Motion to showcase selected frontend projects and professional experience.

## ✨ Features

- Clean, minimal UI with a focus on readability and structure
- Smooth animations using Framer Motion
- Responsive design for all devices
- Structured project presentation with impact-driven descriptions

## 🧠 Projects Highlight

- AI Notes: AI-powered note-taking application with automated content generation
- Admin Dashboard: Data management interface with filtering, sorting, and pagination

## 🛠 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
